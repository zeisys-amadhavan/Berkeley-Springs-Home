# Berkeley Springs Home

This repository stores metadata and working materials for the Berkeley Springs home.

It is intended to hold the home's documentation over time, including:

- photographs and visual references
- design simulations
- work estimates and contractor pricing
- renovation and improvement projects
- drawings, plans, diagrams, and measurements
- landscaping, pool, exterior, and interior project information
- Airbnb preparation and related property planning
- other records useful for maintaining, improving, and documenting the home

The repository is a working record of the property rather than a software project.
